# Body anatomy

A skill body is executable conditioning. Its job decides its shape.

Keep only:

- non-obvious invariants;
- dangerous edges;
- exact input, output, or state contracts;
- explicit stop conditions;
- conditional procedures with a load trigger; and
- guards backed by observed failure.

Use a title. Add headings only when they separate real phases or contracts. Artifact authors retain
their required Artifact, Verify, Decision, Output, and Close sections where applicable. Universal
methods carry none by ritual.

Use hard verbs. Delete encouragement, scene-setting, default behavior, repeated rationale,
announcement labels, ceremonial negatives, and conclusions. State each fact once.

Keep the complete procedure in `SKILL.md`. Condense long detail; never hide required control in an
appendix another read can skip.

Render chat with Markdown headings, labels, lists, and tables. Fence only literal code, untouched raw
evidence, or an artifact template.

Numbering, rationale, examples, anti-patterns, and headings are tools. If removing one changes
nothing, remove it.
